# Cloud Provider Comparison

## Introduction

For this checkpoint, I researched the official documentation of AWS, Microsoft Azure, and Google Cloud. I compared their services based on the four infrastructure components required in this activity: compute, storage, networking, and identity and access management.

## Cloud Service Comparison

| Infrastructure Component                 | AWS        | Microsoft Azure                 | Google Cloud Platform |
| ---------------------------------------- | ---------- | ------------------------------- | --------------------- |
| **Compute**                              | Amazon EC2 | Azure Virtual Machines          | Compute Engine        |
| **Storage**                              | Amazon S3  | Azure Blob Storage              | Cloud Storage         |
| **Networking**                           | Amazon VPC | Azure Virtual Network           | Google Cloud VPC      |
| **Identity and Access Management (IAM)** | AWS IAM    | Microsoft Entra ID / Azure RBAC | Google Cloud IAM      |

The three providers have different names for their services, but they provide similar basic infrastructure functions. For example, Amazon EC2, Azure Virtual Machines, and Compute Engine all provide virtual computing resources, while Amazon S3, Azure Blob Storage, and Cloud Storage provide cloud storage. AWS VPC, Azure Virtual Network, and Google Cloud VPC provide networking capabilities for cloud resources.

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

I think **AWS** offers the broadest range of cloud services. It has many services for computing, storage, networking, databases, security, AI, and other cloud needs, so it can support many different types of projects.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend **Microsoft Azure** because it works well with Microsoft products and technologies. Organizations that already use Windows, Microsoft 365, SQL Server, and other Microsoft services may find Azure easier to integrate into their existing environment.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

I would choose **Google Cloud** for this area because Google has strong technologies related to AI and machine learning. It also provides **Google Kubernetes Engine (GKE)** for running and managing Kubernetes workloads.

### 4. What similarities did you observe among the three cloud providers?

The main similarity I noticed is that all three providers offer the basic infrastructure needed to build cloud systems. They all provide compute, storage, networking, and identity or access management services, although the service names and features are different.

## My Observation

After comparing the three providers, I noticed that they are more similar than I expected. The names of the services are different, but their main purpose is almost the same. This helped me understand that learning the basic cloud infrastructure concepts is more important than memorizing the name of one provider's services.
