# Checkpoint 3 – Identify Cloud Infrastructure Components

Using the Linux environment provided by KillerCoda, I was able to observe different infrastructure components. These components are important because they work together to make a computer system and cloud environment function properly.

## 1. Compute Resources

**Example:** CPU

**Purpose:**
The CPU is responsible for processing commands and running programs. It performs the tasks needed by the Linux system.

**Importance in Cloud Computing:**
Compute resources are important because cloud applications need processing power to run programs, websites, and services. Cloud providers allow users to use computing resources without having to own a physical server.

**Relation to KillerCoda:**
In the KillerCoda Linux environment, I observed that the system has an Intel Xeon processor with one available CPU core. This CPU is used to run the Linux commands and applications inside the virtual environment.

## 2. Storage Resources

**Example:** Disk Storage

**Purpose:**
Storage is used to save files, programs, system files, and other data.

**Importance in Cloud Computing:**
Storage is important because cloud systems need a place to store user files, databases, applications, and other information. It also allows data to be accessed when needed.

**Relation to KillerCoda:**
The Linux environment provided by KillerCoda has a disk with around 19 GB of storage. The disk contains the files and system components needed for the Linux environment to operate.

## 3. Networking Resources

**Example:** Network Interface

**Purpose:**
Networking allows the computer to communicate with other computers, servers, and the internet.

**Importance in Cloud Computing:**
Networking is important in cloud computing because cloud services depend on network connections. It allows users to access applications, transfer data, and communicate with cloud servers.

**Relation to KillerCoda:**
The KillerCoda Linux environment uses networking to connect the virtual machine to the internet. This allows me to use commands and access resources that require a network connection.

## 4. Operating System

**Example:** Ubuntu 24.04.4 LTS

**Purpose:**
The operating system manages the computer's hardware and provides an environment where programs and commands can run.

**Importance in Cloud Computing:**
An operating system is important because cloud servers need an OS to manage their resources and run applications. Linux is commonly used in cloud environments because it is flexible and reliable.

**Relation to KillerCoda:**
The environment I used in KillerCoda runs **Ubuntu 24.04.4 LTS** with a Linux kernel. I used the terminal to check system information and perform different commands.

## Summary

The Linux environment in KillerCoda showed me how compute, storage, networking, and the operating system work together. These components are also the basic parts of cloud infrastructure. By observing them directly, I was able to better understand how cloud computing uses physical and virtual resources to provide services to users.
