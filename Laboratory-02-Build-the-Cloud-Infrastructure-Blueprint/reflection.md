# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, the **compute resource** is the most important component because it provides the processing power needed to run applications and services. Without compute resources, the system would not be able to perform tasks even if it has storage and networking.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and flexible operating system for servers. During this activity, I used Linux commands to check the server's CPU, RAM, storage, operating system, hostname, and IP address. This helped me understand how cloud servers can be managed using a terminal.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it keeps important information about the infrastructure organized. It helps engineers understand the system and can prevent mistakes during deployment. It is also useful when troubleshooting or when another person needs to manage the infrastructure.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using different commands and identify its compute, storage, networking, and operating system resources. I also improved my skills in creating Markdown files, using Git and GitHub, and comparing services from AWS, Microsoft Azure, and Google Cloud.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized because I added a complete laboratory folder with different reports and documentation. I also learned how to make commits and push my work to GitHub. The activity helped me practice organizing my work and presenting my technical knowledge in a clearer way.

## Conclusion

Overall, this laboratory helped me understand how the different parts of cloud infrastructure work together. I also became more comfortable using Linux and GitHub, which I think will be useful for my future activities as an IT student.
