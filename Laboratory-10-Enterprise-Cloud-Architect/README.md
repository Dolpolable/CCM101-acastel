## Project Overview
This repository contains the architecture specifications, Infrastructure as Code (IaC) configuration, automated disaster recovery scripts, and operational manual for Mission 10[cite: 1, 2, 3]. 

The mission objective is to design, deploy, harden, and automate a multi-tier, containerized cloud infrastructure on a headless Ubuntu Server virtual machine with zero guided tutorials, ending in a live simulated boardroom defense.
